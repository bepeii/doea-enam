# Doea Enam — Dashboard Keuangan (aplikasi HP)

Aplikasi web (PWA) yang bisa dipasang di HP Android dan iPhone: https://bepeii.github.io/doea-enam/

- Halaman ini hanya "cangkang": tampilan dashboard dan semua data diambil dari Google Apps Script proyek **Dashboard Doea Enam**.
- Untuk mengganti server, ubah nilai window.DE_API_URL di index.html.
- Akses butuh akun: daftar dengan email → verifikasi kode email → disetujui admin.

Cara memasang:
- **Android (Chrome):** buka link, ketuk **Pasang** atau menu ⋮ → *Instal aplikasi*.
- **iPhone (Safari):** buka link, ketuk **Bagikan** → *Tambahkan ke Layar Utama*.
